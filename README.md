## Project Overview

**Educanest** is a comprehensive multi-platform ecosystem designed to modernize early childhood education management. It bridges the communication gap between parents, educators, and kindergarten administration by replacing outdated paper notes and fragmented messaging apps with a centralized, secure web and mobile platform.

The platform provides real-time activity feeds, nutritional meal tracking, structured student evaluations, behavioral remarks, schedule/timetable oversight, and direct role-based instant messaging.

1. **Backend (`/backend`)**: Built with Node.js, Express, and MongoDB (Mongoose), providing secure RESTful APIs, JWT authentication, data validation, rate limiting, and Socket.io for messaging.
2. **Web Portal (`/frontend`)**: Developed with React 18, Vite, and Tailwind CSS for kindergarten directors and administrative staff. Features analytics dashboards, meal planning, user registration, and messaging inbox.
3. **Mobile Application (`/mobile`)**: A cross-platform Flutter application tailored for parents and teachers with role-based navigation, progress tracking, timetables, and real-time chat.
